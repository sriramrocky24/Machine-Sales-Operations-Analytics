# Machine Sales Operations Analytics (Power BI)

## Project Overview
This Power BI dashboard analyzes sales, profit, supply chain and machine performance.

## Business Questions
- Which region/product gives highest sales & profit?
- Which supplier did more delivery?
- Which machine had great performance?

## KPIs
- Total Sales
- Total Profit
- Total Quantity Supplied/Sold
- Machine Performance

## Tools Used
- Python
- Excel
- Power BI

## Files
- Machine_Sales_Operations_Analytics.pbix (Dashboard file)
- Machine Business Dataset.xlsx (Dataset)
- Screenshots (Dashboard images+Data Model)
- Python Coding in Notepad

## How to Open
1. Download PBIX file
2. Open in Power BI Desktop
3. Explore dashboard
